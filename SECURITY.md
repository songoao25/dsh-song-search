# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Email the maintainer through the contact information on the GitHub profile, including a description, reproduction steps, and impact.

Never include a real API key in an issue, pull request, log, or repository file.

## Scope

The plugin handles Exa API keys locally and sends them only to Exa for search requests. Reports involving key disclosure, cross-origin configuration writes, or unexpected data transmission are especially important.
